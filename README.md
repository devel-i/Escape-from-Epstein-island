# Побег с острова Эпштейна — полноценная 2D игра с управлением

Теперь в репозитории **две версии игры на разных языках программирования**:

1. **Desktop (Python + Pygame)** — основной полноценный вариант.
2. **Web (JavaScript + Canvas)** — дополнительная версия на другом языке.

## 1) Python/Pygame (desktop)

### Возможности
- 2D-карта с препятствиями;
- управление персонажем: `WASD` или стрелки;
- взаимодействие `E` с терминалами;
- 3 головоломки (получение ключ-карт);
- выход с уровня только после выполнения условий;
- окно ответа с вводом текста и проверкой.

### Запуск
```bash
python3 -m pip install pygame
python3 main.py
```

## 2) JavaScript/Canvas (дополнительная версия)

### Возможности
- 2D-версия с управлением и сбором 3 карт;
- управление: `WASD`/стрелки;
- действие `E`, сброс `Esc`.

### Запуск
```bash
cd web_game
python3 -m http.server 8000
```
Открой: <http://localhost:8000>
